How to use this tracker
  • Drag a seat onto another seat to swap their occupants.
  • Click a seat to edit the occupant, account, or new-hire status.
  • Edits are staged as a draft first — use Save Full Seat Plan to commit them, or Discard to cancel.
  • Use Site (top right of the floor plan) to switch between HQ and Candelaria seat plans.
  • Version History lets you preview or restore a previously committed layout.
  • Open a seat and use Duty Schedule → ⚙ Manage Account Schedules to set the default duty hours for every account on the current site — a seat then shows a green dot when that agent is on shift right now, gray when off shift.
  • Use Duty Schedule to give one agent a custom schedule instead of the account default, or check Resigned / Rendering to mark them with a red dot.
  • Export downloads the current live seat plan to Excel.
